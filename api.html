Pokemon Info

About This API

PokeAPI returns information about Pokemon as JSON. I chose it because it is free, and has cool information about pokemon.

Where I Found It

https://pokeapi.co

Parameters Used

The Pokemon name (charizard) is the only information I had to give the API and it goes just at the end of the API.

Example Use Case

A Pokemon fan site could use it to show a Pokemon's picture and stats for a game their building about Pokemon.
